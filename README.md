# Space Shooter / Galactic Battle

A complete 2D space shooter game built with LibGDX on a Redmi 9A (2GB RAM, arm32) using Sketchware Pro.

**No PC. No Android Studio. Just a phone and a dream.**

## Features

- 🚀 **5 boss types** — Normal, Fast, Tank, Spread, Shield (each with unique attacks)
- 👾 **3 enemy types** — Fighter, Interceptor, Battleship (different HP, speed, patterns)
- 🛡️ **Base defense** — protect your base, it regenerates over time
- 🎨 **16 loadouts** — 4 ship skins × 4 bullet colors (unlock in shop)
- ⚡ **5 power-ups** — Extra Life, Rapid Fire, Shield, Coin Magnet, Damage Boost
- 🏆 **10 achievements** — with coin rewards
- 💰 **Full shop system** — buy ships and bullets with coins
- 🎵 **Complete audio** — music + 6 sound effects
- 📊 **Difficulty system** — Easy, Normal, Hard

## How to play

- **Drag** anywhere to move your ship
- **Auto-shoot** — no tapping needed
- **Protect the base** at the bottom
- **Collect power-ups** dropped by enemies
- **Defeat bosses** every 500 points

## Install

1. Download the APK from [Releases](../../releases)
2. Enable "Install unknown apps" for your file manager
3. Install and play

## Tech stack

- **LibGDX** — cross-platform game framework
- **Sketchware Pro** — Android build system
- **Pure procedural graphics** — no image assets, everything drawn with code
- **Single-file state management** — GameState holds everything

## Built on

- Redmi 9A (2GB RAM, arm32, Android 10)
- Termux + Sketchware Pro
- No PC, no IDE, no laptop
